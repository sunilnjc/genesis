# Brand marks

Row marks are local SVGs with each brand’s own fill. No CSS mask, no `currentColor`, no white-on-charcoal.

- **Simple Icons** (CC0), painted with the SI hex: Claude `#D97757`, Cloudflare `#F38020`, Cursor `#000000`, X `#000000`, plus sample-stack marks (GitHub, Notion, Figma, Linear, …).
- **OpenAI**: Simple Icons removed the slug; the blossom is the historical SI 11.14 path, filled with SI’s OpenAI hex `#412991`.
- **CoinGecko**: gecko-in-coin from the public lockup (no SI slug), painted with the mascot green `#40C000` and yellow `#F0E060`.
- Near-black official marks (Cursor, X, GitHub, …) sit on a light plate so the real glyph reads on charcoal instead of being recolored white.
